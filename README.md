# Concord POC — Examples

Example scripts for the [Concord POC](https://github.com/matsljunggren-concord-design/concord-poc) machine control app.

**[User Guide](https://matsljunggren-concord-design.github.io/concord-poc-examples/user-guide)** · **[Download app](https://github.com/matsljunggren-concord-design/concord-poc/releases/latest)**

## Using these examples

1. Download and install the app from the [releases page](https://github.com/matsljunggren-concord-design/concord-poc/releases/latest)
2. Clone or download this repo
3. In the app, open the **Examples** tab, click **Browse examples folder**, and select this folder
4. Select a script and click **Run**

## Writing your own scripts

See the [User Guide](https://matsljunggren-concord-design.github.io/concord-poc-examples/user-guide) for the script format and available API.
